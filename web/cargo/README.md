# Сайты грузоперевозок

Три одностраничных сайта, по одной машине на сайт. Отдаёт `web-gateway`:

| Порт | Папка | Машина | Для кого |
|------|-------|--------|----------|
| 8085 | `line/` | Mercedes-Benz Actros + тент 13,6 м | Компании: рейсы по Балтии и Европе |
| 8086 | `furgon/` | Peugeot Boxer L3H2, 13 м³ | Частные лица: переезды по Таллинну |
| 8087 | `tent/` | VW Crafter с тентом 4,2 м, кат. B | Стройка и склады: паллеты в городе |

Без сборки и бэкенда: HTML + CSS + JS. Заявка уходит в WhatsApp
с готовым текстом (`wa.me`), звонок — по `tel:`.

## Что заменить перед запуском

Всё ниже — заглушки:

- телефоны `+372 5000 0101/0202/0303` в `index.html` и `WHATSAPP` в начале `js/app.js`;
- `info@example.com` в подвале «Белой линии»;
- цены (`RATE_*`, `PRICE` в `js/app.js` и таблицы цен в `index.html`);
- названия «Белая линия», «Фургон за час», «Тент Б».

Фото — Wikimedia Commons, подписи авторов в подвале каждого сайта обязательны
(CC BY-SA для Actros и Crafter). На фото Boxer и Crafter размыты номера,
на тенте Crafter — чужая реклама.

## Что взяли из анализа рынка

Смотрели Moving24 и Kolimisabi (Таллинн), Perevozka24, «Везёт всем» и
Dostavista (Россия), Lalamove и Two Men and a Truck. Грузовичкоф
недоступен из Эстонии (403).

- **Цена на первом экране.** Сильные сайты (Moving24) ставят форму или
  расчёт рядом с заголовком. Слабые (Kolimisabi) прячут цену за
  «персональным предложением» — человек уходит звонить конкурентам.
- **Короткая форма.** Каждое лишнее поле снижает число заявок. У нас
  2–4 контрола и мгновенный ответ, телефон и имя не просим — их видно в WhatsApp.
- **Машина важнее компании.** Perevozka24 и Lalamove показывают машины
  карточками с грузоподъёмностью. Клиент думает «влезет ли», поэтому
  у каждого сайта своя интерактивная проверка: маршрут, объём вещей,
  раскладка паллет.
- **Звонок в один тап на телефоне.** Почти все показывают телефон в шапке;
  на мобильном у нас закреплённая панель «Позвонить / WhatsApp».
- **Доверие без выдумок.** У конкурентов — отзывы Google и счётчики
  заказов. Пока отзывов нет, их не рисуем: вместо этого честные условия
  (CMR, оплата по факту, что не возим). Когда появятся настоящие отзывы
  Google — добавить блок со ссылкой на них.
