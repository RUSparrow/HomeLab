    Частые вопросы

    Застрахован ли груз?

    Да, ответственность перевозчика застрахована по конвенции CMR. Для дорогого груза оформим дополнительную страховку на полную стоимость.

    Какие документы нужны?

    По ЕС достаточно счёта или накладной на груз, CMR оформляем сами. Для экспорта за пределы ЕС понадобится таможенная декларация — подскажем брокера.

    Как быстро подадите машину?

    По Эстонии обычно на следующий рабочий день. Международный рейс планируем за 2–3 дня.

    Как оплатить?

    Компаниям — по счёту после выгрузки. Частным лицам — 30 % предоплаты, остальное после доставки.
