# Картины из ячеек Excel

`mona-lisa.xlsx` — «Мона Лиза» Леонардо да Винчи, нарисованная заливкой ячеек:
160 × 238 квадратных ячеек по 12 × 12 px, 256 цветов. Открывается сразу в
масштабе 32 %, чтобы картина была видна целиком; приблизьте — увидите «пиксели».
На втором листе — откуда картинка и как её пересобрать.

Сделать свою:

```bash
pip install pillow openpyxl
python art/make_pixel_art.py фото.jpg картина.xlsx --cols 160 --colors 256 --title "Название"
```

- `--cols` — ширина в ячейках (высота считается по пропорциям). Больше — подробнее, но тяжелее файл.
- `--colors` — размер палитры; 256 хватает почти для любой картины.
- `--preview out.png` — заодно сохранить PNG того, что получится.

Исходник: `mona-lisa-source.jpg` — фото картины из Лувра (C2RMF) с Wikimedia Commons,
общественное достояние.
