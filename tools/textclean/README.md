# textclean

Чистит текст от следов ИИ перед отправкой письма.

- **Автоматически исправляет:** невидимые символы (zero-width, метки направления, tag-символы/водяные знаки, мягкие переносы), неразрывные и типографские пробелы, длинные и короткие тире, «ёлочки», „лапки“ и “кавычки”, символ …, маркеры •, markdown (`**`, `###`), подменённые буквы (латинская `e` в русском слове и наоборот).
- **Только показывает:** фразы-штампы (et/ru/en), предложения длиннее 25 слов, слова от 18 букв.

Правила лежат в одном файле, `web/server-monitor/frontend/textclean/rules.json`. Их используют и скрипт, и веб-страница.

## Использование

    textclean письмо.txt                 # отчёт
    textclean --fix письмо.txt > чисто.txt
    textclean --fix --lang et -          # из stdin
    textclean --json --fix письмо.txt    # для скриптов

Веб-версия: `http://<сервер>:8080/textclean/`. Весь расчёт идёт в браузере, текст на сервер не отправляется.

Тесты: `python3 -m unittest discover -s tools/textclean`
